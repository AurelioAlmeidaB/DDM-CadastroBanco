# Cadastro com Banco de Dados

Cadastro de contatos (nome e telefone) salvo em banco de dados SQLite no próprio celular.

## O que o app faz

- Permite **incluir**, **alterar**, **excluir**, **pesquisar** pelo código e **listar** os registros.
- Usa `SQLiteDatabase` e View Binding.

## Sobre

Projeto da disciplina de **Desenvolvimento para Dispositivos Móveis (DDM)** — IFSP Campus Votuporanga.
Atividade de aula — banco de dados no Android.

Feito em Kotlin no Android Studio.
